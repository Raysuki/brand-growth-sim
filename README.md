# 品牌养成计划
![游戏名 Logo](assets/icons/游戏名logo.png)\

一款使用 Godot 4.6.2 制作的 2D 品牌成长模拟养成游戏 MVP。玩家通过品牌定位、产品开发、传播推广、用户沟通与危机处理等行动，推动品牌从初创期走向成长期、成熟期，并触发不同结局。

## 项目展示

![主界面截图](assets/icons/屏幕截图%202026-05-25%20180041.png)

## 当前功能

- 24 回合经营流程
- 五项品牌属性：品牌知名度、品牌认知度、品牌联想度、品牌忠诚度、渠道掌控力
- 资金、行动点、舆情风险系统
- 市场调研、产品研发、视觉设计、营销推广、渠道建设、用户运营、危机公关七类行动
- 风口刷新与行动匹配
- 事件与结局判定
- 可在 Godot 编辑器中拖拽调整的主界面节点结构

## 运行方式

1. 安装 Godot 4.6.2 或兼容的 Godot 4.x 版本。
2. 使用 Godot 打开本项目目录。
3. 运行 `res://scenes/Main.tscn`。

## 项目结构

- `scenes/`：Godot 场景文件
- `scripts/`：核心逻辑与 UI 脚本
- `data/`：玩法数值、行动、事件、结局等 JSON 数据
- `assets/`：背景、图标、UI、NPC 与看板娘素材
- `tests/`：基础烟测场景
- `docs/screenshots/`：README 展示截图

## 说明

当前版本是可玩 MVP，重点验证品牌成长模拟的核心循环。美术、数值与 UI 布局仍可继续迭代。
